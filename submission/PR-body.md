Adds Taskman Journal, a standalone manual task journal with logged-in tick timing, per-skill XP, task tiers and ordered completion history.

Users can add historical or incidental completions with N/A, Passive or known durations, expand history details, filter by tier, undo the latest completion, delete records and export CSV/JSON backups.

Production performs no network requests, handles no credentials and automates no gameplay. Journals are stored locally per account; exports use a user-selected destination. Uses the standard build and RuneLite transitive dependencies only.

Validation: Java 11 compilation against RuneLite 1.13.1 with Gson 2.8.5; 94 core and 32 headless integration assertions passed. Plugin Hub CI and reviewer approval remain required.
